# TextStats

TextStats currently supplies immutable `TextStats` values and silent whole-text counting through `count_text` on Python 3.11+. Named-file counting, the module-entry CLI and source distribution remain planned. The [project brief](docs/dev/PROJECT.md) captures the requested capabilities and delivery boundaries; complete runnable usage instructions will be added with the documentation milestone. Current task evidence and the paused Phase 1 boundary are recorded in [TASKS](docs/dev/TASKS.md#t-001-completion-evidence).
