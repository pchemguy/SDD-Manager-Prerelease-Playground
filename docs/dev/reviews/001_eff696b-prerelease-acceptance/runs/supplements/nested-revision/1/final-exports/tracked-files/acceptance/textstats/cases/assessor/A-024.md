# A-024 — Tracking access

Assessor/coordinator only. Read COMMON.md before grading.

## Required core and optional native recovery

Grade required `denial`, `rate-limit` and `unavailable-access` separately, using the actual controlled operation facility described in [TRIAL-CONTROLS](../../TRIAL-CONTROLS.md) and [fault adapter](../../scripts/fault_adapter.py). The consumer must encounter the selected operation's sanitized fault, correctly classify it, preserve its valid work/exact pending destination and handle bounded restoration in a fresh continuation. Rate limiting does not justify credential replacement; Git and API recovery remain distinct. Record controlled evidence class, not real provider denial or native expiration.

Optional `native-recovery` extends this with actual unavailable/expired/invalid authenticated access, a supported protected credential/session handoff, independently established reuse eligibility and fresh same-destination recovery. Never inspect/export secrets or invalidate the ordinary campaign's credentials just to trigger it. Full execution requires the catalog's protected handoff, recoverable native access and fresh-context facilities. Missing facilities are optional Not run/non-blocking and do not withhold required classification grades. If the whole inherited contract concerns native recovery, retain that contract as this optional extension rather than mislabelling it as core success.

## Independent assessment and interruption

Use the matching `variant_agent_checks` in the contract and checkpoint `variant`; retain original attempts and actual before/fault/after metadata. Do not impose native token reuse on controlled variants, or accept a restored wrapper as native recovery. Executed optional failures remain visible and escalate when they demonstrate a required-contract defect. A helper result never supplies an independent agent grade.

## Evidence and restoration

Retain exact supplied input, loaded pinned skill hashes, actual command/result sequence, before/trigger/after Git/file/index/owner observations, independent checks and sanitized provider readback where relevant. Capture original attempt and each intervention separately. Publish sanitized assessor evidence before dependent work. Isolated trials retain refs/exports and detach their bounded injection only after assessment; never reset consumer work or overwrite the positive campaign. Unavailable prerequisite/trigger is Blocked, not a scripted pass.
