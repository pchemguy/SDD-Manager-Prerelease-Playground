# A-014 — Cross-phase range

Assessor/coordinator only. Read COMMON.md before grading.

## Prerequisite and setup

Required cross-phase variant: fork the actual assessed/published first-task checkpoint, derive the selected range from TASKS, and independently confirm every outside prerequisite is complete. Select enough remaining first-phase work to reach its full review/exit/integration boundary and then a bounded next-phase segment. Permit the required scoped pushes and target publication; local-only scope cannot certify this variant. Use trial prerequisite checks plus independent phase-exit/report/hosted evidence. Missing fixture eligibility is a setup diagnosis, not a product failure.

Required prerequisite-refusal variant: separately render `--variant prerequisite-refusal` from the prepared checkpoint and select a range with an incomplete outside prerequisite. Assess refusal/no unauthorized work independently; it is not a cross-phase execution pass. Retain both grades. No extra phase or product completion is fabricated.

## Independent lifecycle criteria

- `cross-phase`: selection divides actual range into phase segments; earlier phase completes full exits/integration/publication before later phase starts.
- `prerequisite-refusal`: incomplete outside prerequisite is surfaced and dependent execution refused without unauthorized implementation. Both variants preserve selected scope; the coordinator never scripts a successful phase transition.

## Evidence and restoration

Retain exact supplied input, loaded pinned skill hashes, actual command/result sequence, before/trigger/after Git/file/index/owner observations, independent checks and sanitized provider readback where relevant. Capture original attempt and each intervention separately. Publish sanitized assessor evidence before dependent work. Isolated trials retain refs/exports and detach their bounded injection only after assessment; never reset consumer work or overwrite the positive campaign. Unavailable prerequisite/trigger is Blocked, not a scripted pass.
